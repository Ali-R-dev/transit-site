Colophon

How this site is built

Every page is written in React and TypeScript, rendered to static HTML at build time, and served from GitHub Pages. The browser receives no framework: the moving trains, the journey planner, the theme switch and the contact form are a few kilobytes of plain TypeScript, and the site works without them.

The map is generated from a single data file, so adding a project adds a station. Page changes use native cross-document view transitions where the browser supports them. Type is set in Archivo, whose width axis does the job of a signage typeface.
